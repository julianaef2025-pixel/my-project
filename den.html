Common questions

Do I need to pay to use DEN?
No. The Free plan gives you unlimited messages and image generation with no credit card required. Just bring your own Groq API key (free at console.groq.com).
What is DEN Code?
DEN Code is a specialized AI mode tuned for software engineering. It writes clean, production-ready code, debugs issues, writes tests, and reviews for security — in any language.
How does the image generator work?
DEN uses Pollinations AI to generate images — completely free, no extra API key needed. Just describe what you want and choose a style.
What model does DEN use?
DEN uses Llama 3.3 70B via Groq for fast, high-quality responses. Pro users get priority access during peak usage.
